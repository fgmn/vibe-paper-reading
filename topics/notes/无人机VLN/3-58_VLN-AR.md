## 一句话总结

高飞组把无人机 VLN 做成"**VLM 出意图 + 传统规划器出轨迹**"的两层结构：微调过的 Qwen3-VL（4B 为主）每 0.5 秒看 8 帧历史 + 当前帧，输出机体系下的 3D 航点和偏航角 / 2D 框 / 思维链，以及"子任务完成""需要重规划"两个标志；下层是基于 Ego-Planner 改的免学习动作专家，200 Hz 以上生成避障、满足动力学的轨迹。训练数据来自 3DGS 重建 + Unity 的全自动造数流水线（约 400 万样本），三阶段训练（通用 grounding/推理 SFT → 导航 SFT → 闭环 GRPO），外面再包一层带记忆和任务拆分的智能体。整套在 80 g 的 Jetson Orin NX 模块上跑，靠指令引导的 ViT token 剪枝和算子级优化把单步推理从约 4.1 s 压到约 0.5 s。

## 要解决什么问题

作者列了四个难点（§I）：

| 难点 | 说法 | VLN-AR 的对策 |
|---|---|---|
| 3D 数据少、域差大 | 导航大模型多在地面视角 2D 数据上预训练；现有无人机数据集多是室外、纹理粗，sim-to-real 差距大 | 3DGS 实景重建 + 自动造任务、规划、采集（§III-B） |
| 动作表示和安全控制不匹配 | 端到端连续动作保证不了安全和动力学可行；离散语义动作又不够灵活 | VLM 只出 3D 位姿 / 框 / 思维链，交给规划器（§III-A1） |
| 长程推理不够 | 现有方法多是单帧或短时决策，室内长程任务要整合历史、条件推理、拆分子任务 | 认知智能体：任务拆分 + 动态记忆 + 启发式探索（§IV-B） |
| 机载算力紧 | 小无人机有尺寸、重量、功耗（SWaP）限制 | token 稀疏化 + 算子优化 + 低精度量化（§III-A2、§IV-C） |

和前作 VLA-AN 的关系（§I 末段，作者原话的意思）：本文是 VLA-AN 的大幅扩展。VLA-AN 已经有 3DGS 数据流水线、分层架构、训练框架和机载部署栈的初版；**本文新增的是认知导航智能体、指令引导的 token 稀疏化、更丰富的结构化输出（框、思维链、完成 / 重规划标志）**，并扩充了训练、鲁棒性评测和测试场景。

## 方法

总览见 [[topics/papers/无人机VLN/3-58_2611.23930_VLN-AR.pdf#page=1|图 1（第 1 页）]]，模型结构见 [[topics/papers/无人机VLN/3-58_2611.23930_VLN-AR.pdf#page=4|图 3（第 4 页）]]。

### 分层结构（§III-A1）

- 整体写成 π_VLN-AR = φ_LF ∘ π_VLM：上层 VLM，下层免学习（learning-free）动作专家。
- **输入**：语言指令 L，K = 8 帧历史 RGB（间隔 0.5 s，共 4 s）、当前 RGB、位姿 p_t。
- **VLM 输出**五项：
  - y_pose：机体系下的 3D 航点 + 期望偏航（米、度）
  - y_bbox：图像上的 2D 框
  - y_reason：思维链形式的导航意图
  - y_finish：当前子任务是否完成
  - y_replan：当前观测是否不足、需要重规划
- **按任务类型选目标表示**：
  1. 目标导航：优先用 2D 框，取框内平均深度，换算成 3D 航点和偏航。
  2. 空间关系（"到物体右边""穿过圆环"）：目标点不在物体表面，用框 + 深度推不出来，VLM 直接输出 3D 位姿。
  3. 视野里没有任务相关信息：靠思维链在累积观测上推断可能的区域，直接给探索航点。
- y_finish 和 y_replan 只给上层调度用，不进下层执行。
- **动作专家**：在 Ego-Planner 基础上改的，校验并细化局部轨迹，负责避障和缩短飞行时间；Orin NX 上控制频率 >200 Hz。作者特意拿它和 π0 的 0.3B flow-matching 动作专家对比，强调轻量。VLM 推理 2 Hz，与执行异步。

### 指令引导的 ViT token 稀疏化（§III-A2，图 4 第 5 页）

- 动机：在 Orin NX 上延迟大头在 ViT（多图输入，注意力二次复杂度）；航拍画面大片是天空、重复纹理。
- 历史帧先降到 320×240，当前帧保持 640×480。
- 打分：用 Qwen3-VL 自己的语言嵌入表示指令，用预训练视觉投影把中间层视觉特征投到同一空间，算每个视觉 token 与每个文本 token 的余弦相似度，取最大值作为相关度。
- 在 ViT 第 12、15、22 块（从 0 计）各剪一次，Top-K 按固定比例保留，累计保留 75% → 50% → 25%；保留的 token 带原始空间索引继续往下。
- 图 4 里最终是历史帧每帧 4 个 token、当前帧 64 个 token 进 LLM。
- **只在推理时开启**，SFT 和 RFT 都不开。思路来自 QG-VTC、FlashVLM、LaCo 等层内压缩工作。

### 全自动 3DGS 造数（§III-B，图 5 第 6 页）

一个脚本跑完三阶段：

1. **场景重建与标注**：拍室内（办公室、走廊）和室外（公园、街道）视频 → 3DGS → 导入 Unity；用 InstaScene 提取布局、物体标签、3D 框、地图等语义。
2. **自动生成导航任务**：
   - "反向"造任务：先在地图的安全区采起点终点和朝向，再用规则模板或 VLM 合成指令（如"去茶几，去水槽，去房间"）。
   - 带 RGB、深度、激光雷达的无人机用数值优化轨迹规划器（MINCO 系，参考文献 [52]）规划，考虑避障、高度、动力学、平滑和时间最优，可以纵向绕障。
3. **采集**：自适应飞控跟踪轨迹，10 Hz 记录 RGB、深度、点云、6-DoF 里程计；做轨迹和观测随机化。然后：
   - 用 Qwen3-VL-32B 看多帧画面改写指令，变得更丰富（如把三段短指令改成带"客厅里的茶几""观察周围布局"的长句）。
   - 过滤：终点与真值误差 <1 m 才留；改写后的指令用 Doubao 1.8 Pro 检查目标、轨迹、空间关系、约束是否一致。
- 另外混入少量真机数据。总量约 400 万样本，覆盖导航、通用 VQA、grounding、推理、空间 VQA 等。

### 三阶段训练（§IV-A，超参见表 I 第 10 页）

骨干是 Qwen 多模态系列，正文以 Qwen3-VL-4B 为例。

| 阶段 | 数据 | 损失 | 主要超参 |
|---|---|---|---|
| I. grounding-推理增强 SFT（全参数） | VQA、目标 grounding、空间推理、推理 | λ_vqa·CE + λ_bbox·CE + λ_reason·CE（1.0 / 1.0 / 0.3） | bs 32，lr 5e-5，1 epoch |
| II. 导航专用 SFT | 高质量无人机导航轨迹 + 空间推理 | λ_pose·L_reg + λ_finish·CE + λ_replan·CE（1.0 / 0.5 / 0.5） | bs 16，lr 2e-5，2 epoch |
| III. 推理感知导航 RFT | VLM + 动作专家接进闭环仿真，在线 GRPO | 稀疏 0/1 成功奖励；多阶段任务用 R = Σ γ^(j−1) R_j 累加各子任务成功 | 组大小 16，lr 1e-5，温度 0.8，clip 0.2，γ = 0.95 |

- 阶段 III 全组都成功或都失败（σ = 0）的组直接丢掉。
- 消融里说 RFT 时智能体机制（任务拆分、记忆融合、思维链更新）是开着的（§V-D2）。

### 认知驱动的导航智能体（§IV-B，图 6 第 9 页，算法 1 第 8 页）

以 2 Hz 运行，三个机制：

1. **长程任务自动拆分**：任务规划器把长指令拆成子任务队列（如"走到走廊尽头 → 从左绕树 → 左移 10 米 → 找放衣服的椅子"），按 y_finish 逐个出队。
2. **动态多模态记忆融合**：记录历史指令、轨迹、关键帧、任务状态，用来应对遮挡、相似场景，支持"回到之前那张白色餐桌""回起点"这类依赖记忆的任务。
3. **启发式探索**：y_replan = true 时先原地转 360° 主动感知；转完还找不到，就暂停常规航点生成，用思维链结合周围画面、记忆和常识推断目标最可能在哪（如"左边走廊更可能通向目标门"），转成航点去探索；实在找不到就把子任务标为不可达，跳到下一个。

算法 1 里有一个"思考开关"（think on / off），开时用思维链更新子任务队列。

### 机载部署优化（§IV-C）

- 平台：Jetson Orin NX（约 100 INT8 TOPS），感知-计算模块裁到约 80 g。
- 三类手段：
  1. 算法层：上面的 token 稀疏化。
  2. 执行层：针对 ARM 重排注意力计算、重构特征维度、调度算子，SIMD 加速矩阵运算；Flash-Attention、FFN 与归一化融合、KV-cache 预加载、CUDA Graphs。
  3. 低精度：权重和激活（含 KV-cache）都量化（表 III 里是 AWQ）。
- 动作专家这类 CPU 密集模块做流水线化。

## 实验与关键数字

### 设置（§V-A）

- **三个测试集**，作者强调都没参与训练：
  - AerialVLN、OpenFly：室外城市，成功阈值 5 m。
  - 自建 3DGS 室内测试集：约 1 万样本，办公、家庭、商场、影院等，成功阈值 1 m；任务类型包括目标导航、精确导航、空间推理、语言控制、长程（≥3 个子任务）、场景理解、目标搜索、目标跟踪等（比例见图 7）。
- 指标：SR（无碰撞且到阈值内；长程任务要求所有子任务都成功）、NE（长程任务把各子任务误差累加）、TT（成功任务的平均用时）。
- 基线分四类：端到端 VLN、MLLM 智能体、端到端 VLA（OpenVLA、π0 按 UAV-Flow 的设置训练，GR00T N1.5 用"同样的数据"微调）、零样本 MLLM（给同样的输入，要求输出机体系 3D 位姿 + 偏航，交给**同一个动作专家**执行）。

### 真机（§V-C，图 9、10、11，表 IV）

- 两种机型：微分智飞 NCS（D435）和更大的 NCS-α（D455），都带 Orin NX，全机载推理。
- 101 个真机任务（目标导航 30%、空间 grounding 20%、场景推理 20%、长程 10%、跟踪 10%、其他 10%），覆盖物流仓库、家、办公楼、公园、试验场、商业街。**成功 91/101 = 90.1%**。
- 失败**没有一例是碰撞**，主要是到不了精确位置："由近到远第五棵树"这类序数理解不了；勺子这类小目标认不出；D435 运动模糊。
- 鲁棒性（表 IV，各 20 次）：

| 场景 | 成功 |
|---|---|
| 3D 悬空结构（"穿过方框，再在货架上找百事可乐"） | 18/20 |
| 高度变化 >5 m | 19/20 |
| 夜间弱光 | 17/20 |
| 行人突然闯入 | 17/20 |
| 全新场景零样本 | 18/20 |

### 机载推理速度（表 III 第 15 页，图 14 第 18 页）

| 模型 | 计算量 | 优化前 s/token | 优化后 s/token | 加速 |
|---|---|---|---|---|
| 7B-AWQ | ~1815.8 GFLOPs | 1.034 | 0.110 | 9.4× |
| 4B-AWQ | ~946.7 GFLOPs | 0.508 | 0.062 | 8.2× |
| 2B-AWQ | ~563.3 GFLOPs | 0.227 | 0.032 | 7.1× |

- 摘要里的 7.1×–9.4× 就是这三行的解码加速比。
- 图 14：单步总推理从约 4100 ms 降到 494 ms（8.3×）：ViT 2350 → 120 ms，投影 + LLM prefill 550 → 130 ms，解码 1000 → 230 ms。
- 换到 Jetson AGX Thor 上，比 Orin NX 再快 5–10 倍（作者称"few-shot 迁移"）。

### 消融（§V-D）

**训练数据（图 12，第 17 页）**：每种数据约 100 万样本，其余设置相同。

- 只用 mesh 数据最差：目标导航 72.2%、长程 48.1%、空间 grounding 58.3%。
- 3DGS 数据与真机数据效果接近，但能自动扩充。
- 再加多样数据（导航 30%、通用 VQA 15%、空间 VQA 20%、grounding 15%、推理 10%、其他 10%）后长程：mesh 78.0%、真机 88.7%、3DGS（本文）88.0%。

**三阶段训练（表 V，第 16 页，SR %，都带智能体）**

| 配置 | 场景理解 | 空间推理 | 精确导航 | 长程导航 |
|---|---|---|---|---|
| 基线（不训练） | 77.4 | 68.2 | 21.3 | 17.8 |
| 只 Stage I | **87.2** | 94.5 | 28.1 | 22.5 |
| 只 Stage II | 75.6 | 64.3 | 68.5 | 64.4 |
| Stage I + II | 80.2 | 88.3 | 60.6 | 61.5 |
| 只 Stage III | 82.6 | 76.1 | 45.4 | 36.3 |
| 全部 | 85.5 | **94.6** | **85.7** | **88.0** |

- Stage I 管理解，Stage II 管导航；两者叠加反而不如各自的专长（作者归为多任务干扰）；Stage III 把精确和长程导航从约 61% 拉到 86–88%。

**token 稀疏化（图 13）**：保留 25% token 时，指令引导版的目标 token 召回约 92.5%、导航成功率约 91.7%；不做相似度计算的剪枝随保留比例下降明显退化。作者称 25% 附近是拐点。

**智能体（表 VI）**

| | 目标导航 | 空间推理 | 长程导航 |
|---|---|---|---|
| 完整 | 98.1 | 94.6 | 88.0 |
| 去掉智能体 | 95.7 | 92.4 | 57.4 |

- 长程任务受益最大（+30.6 点）。
- 人工检查 976 个仿真长程 episode：完成标志出错 13 次（11 次过早判完成、2 次没切换），约 1.3%，多因离 1 m 阈值只差一点。10 次真机长程试验里没出现。

## 局限 / 存疑

论文自述（§V-C4、§VI）：相似物体多时歧义指令会导致认错目标；多数失败来自语义到 3D 几何的映射（远处或小目标经 2D→3D 投影后坐标偏差，飞过头或不够）。未来工作：动态环境里的时序因果推理、融合点云 / 语义地图、把端到端推理做到 10 Hz 以上。

读的时候值得核对的地方：

- **和前作 VLA-AN 重叠很多**。摘要说的"最高单任务成功率 98.1%"、图 14 的"8.3× 加速"，在 VLA-AN 的摘要里就已经出现过（见专题 3-50 那一行）。本文真正新增的是智能体、token 稀疏化和输出格式。读的时候建议对照 VLA-AN，区分哪些数字是新结果。表 II 里两者都列了，差距（室外 +11~12 点、室内 +5 点）才是新增部分的增益。

## 摘要（中文意译）

无人机需要在严格的机载限制下实现语义推理、智能决策和长程导航。基于基础模型的方法虽有进展，但在复杂环境中仍受限于 3D 数据不足、轨迹可行性、长程推理和计算效率。本文提出分层式空中 VLN 框架 VLN-AR：把多模态推理和底层控制解耦，结构化地预测 3D 位姿指令和导航意图，再转成动力学可行的动作。为缓解数据稀缺和域差，提出基于 3DGS 的全自动流水线，可大规模生成照片级无人机导航数据；三阶段渐进训练依次增强 grounding、场景推理和复杂导航；轻量认知智能体通过记忆感知的任务分解改进长程推理；最后通过 token 稀疏化和模型轻量化等机载优化，在资源受限的无人机平台上实现 7.1–9.4 倍加速，同时保持较高的导航性能。仿真和真机实验都显示相对现有方法有明显提升。原文见 [arXiv](https://arxiv.org/abs/2611.23930)。
